# Short-Form Gameplay Video

## 1. Pick the goal

- **Store preview**: must be real in-game footage; follow store rules (length, no device frames for some stores, check current guidelines).
- **Social post**: personality and a hook; can show development or humour.
- **Ad creative**: one clear hook, a call to action, several variants to test.

## 2. Write the beat sheet (before capturing)

| Time | Beat | On screen | Text overlay | Audio |
|---|---|---|---|---|
| 0–3 s | Hook | The most satisfying or surprising moment | ≤ 6 words | Strong sound |
| 3–15 s | Core verb | 2–3 clean actions with clear feedback | | |
| 15–25 s | Escalation / variety | Bigger combo, new content, progression | | |
| 25–30 s | Payoff + end card | Big reward moment, logo, CTA | Game name | |

Hook ideas: an oddly satisfying moment, a near-fail, a "can you solve this?", a before/after, a big number.

## 3. Capture

- Use a capture build: debug UI hidden, good save data, consistent seed for reproducible moments, 60 fps.
- Record at vertical 1080×1920 (or the game's orientation, reframed). Unity Recorder in the Editor at a fixed frame rate gives clean frames; also record on a real device for authenticity.
- Capture each beat several times; pick the best takes.

## 4. Edit

- Cuts on actions; no dead time; total under the target length.
- Text overlays big and inside safe zones for each platform's UI.
- Sound on: game SFX plus music; also works muted (captions/overlays carry the message).
- End card with name and where to get it.

## 5. Variants

For ads or social: 3–5 variants changing only the hook (first 3 s) to learn what works.

## Output

The beat sheet, a capture list (beat → scene → seed/setup → takes), and the edited video files with their variant names. If a video-editing skill or tool is available in the session, use it for assembly; otherwise deliver the edit plan with timecodes.
